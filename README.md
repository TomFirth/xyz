# Restaurant finder API
This project provides a simple set of REST APIs to manage a restaurant and its menu. Developers are free to ask question or suggestion. 

We’ve included TODOs in the code where we expect the developer to implement the required functionality.

We encourage the developer to approach the solution as they would in their typical day-to-day workflow, including best practices, structure, and tooling.

If needed, the developer may use an in-memory map for data storage.

### About the APIs requirement
- Restaurant should have name, type (e.g. vegan/halal), address
- Dish should have name, price, description
- Menu should have name and list of dishes
- Restaurant should have menus 


### Technologies used
- express js
- typescript
- Mocha and Chai for test
